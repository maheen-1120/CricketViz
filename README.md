# CricketViz 🏏
CricketViz is a simple machine learning project that uses cricket player statistics to predict a player's role, team selection, and expected performance in the next match.

The project is built using Python and Streamlit, with machine learning models from Scikit-learn.

Features
Predicts the player's role, such as Batsman, Bowler, or All-Rounder
Predicts whether the player is likely to be selected in the team
Estimates the number of runs the player may score
Estimates the number of wickets the player may take
Shows the predictions using simple charts
Provides an easy-to-use Streamlit interface
